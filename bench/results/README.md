# Результаты прогонов

Каталог **не хранится в git** (`.gitignore`: `bench/results/*`, кроме этого файла). Результаты локальны: они зависят от
железа, а цифры из чужого окружения вводят в заблуждение. Сравнивать можно только прогоны с одного стенда.

## Раскладка

Один прогон `bench/warp/run.sh` — один каталог:

```
bench/results/<UTC-время>_<короткий-sha>[-dirty]_<режим>_<размер>_c<параллелизм>/
    warp.json.zst     сырые данные warp (в warp 1.3.1 это .json.zst; csv.zst появляется в других версиях). Формат
                      читают warp analyze, warp cmp и warp merge
    analyze.txt       вывод `warp analyze --analyze.v` для этого файла (перцентили, TTFB, разбивка по размерам)
    warp-run.log      то, что warp печатал во время прогона
    meta.json         что именно измерялось (см. ниже)
```

Пример имени: `20261006T225525Z_394f691_get_small_c20`. Суффикс `-dirty` у sha значит, что в рабочем дереве были
незакоммиченные изменения: такой прогон нельзя воспроизвести по коммиту.

`bench/warp/matrix.sh` дополнительно пишет `matrix_<UTC>.tsv`: по строке на прогон (режим, размер, параллелизм,
код возврата, каталог, итоговая скорость).

## meta.json

| Поле | Содержимое |
|---|---|
| `git` | полный и короткий sha, ветка, `dirty`, тема коммита |
| `run` | режим, размер, параллелизм, длительность, число объектов, бакет, `error_free`, код выхода warp |
| `warp` | версия, способ запуска (`local` / `docker`), аргументы (секреты заменены на `***`) |
| `sectoriadb` | образ, переменные окружения `SECTORIADB_*`, `JAVA_OPTS` (секреты скрыты), версия JVM внутри контейнера, `application.properties` на момент прогона |
| `hardware` | `nproc`, модель CPU, RAM, ядро, ОС, файловая система и тип диска каталога данных Docker, `lsblk`, виртуализация |

`error_free: false` значит, что warp сообщил об ошибках запросов: такой прогон нельзя сравнивать с другими (см.
методику в `docs/architecture/08-observability-bench.md`). `run.sh` в этом случае завершается с кодом 3.

## Как сравнивать

```bash
bench/warp/compare.sh 20261006T225525Z_394f691_get_small_c20 20261007T101010Z_abcdef0_get_small_c20
```

Скрипт печатает коммит, режим и железо обоих прогонов перед результатом `warp cmp`; если они различаются больше, чем
одной переменной, сравнение не имеет смысла.
