# S3 в SectoriaDB: что нужно знать

## Главные понятия
- **Бакет** — «папка верхнего уровня». **Объект** — файл внутри бакета. Его ключ — полный путь, например `photos/2026/cat.jpg`.
  Настоящих папок в S3 нет: `photos/` — просто общий префикс в ключах.
- **Access Key ID + Secret Key** — «логин и пароль» для программ (aws cli, s3manager). Секрет по сети не передаётся:
  им подписывается запрос.
- **Всё приватно по умолчанию.** Запрос без подписи получает `403 AccessDenied`. Это нормально и так задумано в S3.

## Как отдать файл другим людям

| Нужно | Способ | Команда |
|---|---|---|
| Файл доступен **всем, всегда** | Публичный объект | `object-acl --bucket B --key K --acl public-read` |
| **Весь бакет** открыт на чтение | Публичный бакет | `bucket-acl --bucket B --acl public-read` |
| Дать файл **на время** одному человеку | Временная ссылка (presigned) | `aws s3 presign s3://B/K --expires-in 3600` |
| Открыть **только папку** | Политика бакета | `aws s3api put-bucket-policy ...` |

Публичный бакет открывает и **список файлов**. Если нужен один файл, открывайте объект, а не бакет.

Команды `object-acl`, `bucket-acl`, `public-list` запускаются так (работают рядом с запущенным сервером):

```bash
X="docker compose exec -T sectoriadb java -jar /app/sectoriadb.jar"
$X public-list                                        # что сейчас открыто, со ссылками
$X object-acl --bucket test-bucket --key photo.jpg --acl public-read
$X object-acl --bucket test-bucket --key photo.jpg --acl private
```

Публичная ссылка выглядит так: `http://ВАШ-АДРЕС:8080/бакет/ключ`. Адрес `sectoriadb:8080`, который показывает
s3manager, — внутреннее имя Docker, снаружи он недоступен.

## Ключи доступа
```bash
$X mk-key --count 3 --desc "для бэкапов"    # создать несколько ключей
$X keys --secret                            # показать ключи с секретами
$X disable-key --id ID                      # временно выключить
$X rm-key --id ID1,ID2 --yes                # удалить
```
Один ключ — одному приложению или человеку: так любой можно отозвать, не ломая остальных.

## Про s3manager
Это сторонний веб-интерфейс. Он удобен для просмотра и загрузки, но:
- не умеет менять доступ (публичность) — используйте команды выше;
- видео через его кнопку воспроизведения не перематывается (он не передаёт `Range`) — открывайте видео по прямой
  публичной или временной ссылке на порт 8080;
- сообщение «file does not seem to be publicly available» значит только, что файл приватный.

## Чего не стоит делать
- Не открывайте бакет с приватными файлами как `public-read`: его содержимое смогут перечислить все.
- Не используйте `public-read-write`: любой сможет загружать и затирать файлы.
- Не храните ключи в git и не отправляйте их в чаты; если ключ засветился — удалите и создайте новый.
